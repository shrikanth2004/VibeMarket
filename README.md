## Running the Project

Because the core of the app is pure HTML/CSS/JS, you can open the entry point directly:

1. Open `index.html` in your browser, **or**
2. Run a local development server for a better experience (recommended):
   ```bash
   npx -y http-server . -c-1
   ```
   Then navigate to `http://localhost:8080`.

If you added any backend scripts (e.g., a Flask API), start them with:
```bash
python -m venv .venv
source .venv/bin/activate  # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
